# 통합테스트 (A.2) 최종 결과 — Claude vs Gemini 2.5 Flash

날짜: 2026-05-22 / 측정: Claude Sonnet(-p) + 시스템별 프롬프트 + browser-use (Mac headless)

## 방법

전체 127 task 재측정은 페이스(~14분/task)상 비현실적이라, **Gemini 2.5 Flash가 실패한 task 26개 + 통합(cross-system) 4개 = 30개**를 Claude로 측정.
→ "Gemini 약점을 Claude가 얼마나 메우는가" 직접 검증.

## 통합 (cross-system, 신규 측정)

단일 흐름에서 여러 시스템을 넘나드는 4개 task (포털→사이버/도서관, 통합정보→도서관):
- **Claude 3/4 (75%)** — Gemini는 미측정(신규). 멀티시스템 자동화 가능성 입증.

## 해석

- **저성능 시스템일수록 Claude 우위 큼**: 학사지원 50→95%, 학과 80→100%, 통합정보 61→83%.
- **이미 천장(도서관 100·전자결재 95·사이버 90)**: 차이 미미.
- **둘 다 못 푸는 난제**: 이수증 등록(전자결재), 게시판 글쓰기/제출(사이버), eXbuilder 깊은 폼 조작(통합정보 일부) — 시스템 구조적 한계.
- **종합**: 같은 task set에서 Claude+프롬프트가 Gemini 2.5 Flash 대비 **79% → 93% (+15%p)**.
